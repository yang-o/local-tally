物业收费登记（Windows）使用说明
================================

【重要】请解压整个压缩包后，进入 Tally 文件夹，再双击运行 Tally.exe。
不要只把 Tally.exe 单独拷贝到桌面或其他目录。

正确目录结构示例：
  Tally\
    Tally.exe
    _internal\          （必须和 exe 在同一目录）
    使用说明.txt

若启动失败：
1. 确认 _internal 文件夹与 Tally.exe 在一起
2. 安装微软 Visual C++ 运行库（x64）：
   https://aka.ms/vs/17/release/vc_redist.x64.exe
3. 暂时关闭杀毒软件对解压目录的拦截后再试
4. 不要放在需要管理员权限的目录中运行
